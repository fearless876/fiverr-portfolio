## Advanced Prompting Techniques

### Chain-of-Thought
```
Solve this problem step-by-step: [PROBLEM]. Steps: 1) Understand the problem, 2) Break into sub-problems, 3) Solve each, 4) Verify solution, 5) Present final answer.
```

### Expert Role-Playing
```
You are a [ROLE] with 20 years of experience. I am your [RELATIONSHIP]. [TASK]. Provide your expert advice: what I'm doing right, what could go wrong, what you'd do differently.
```

### Few-Shot Learning
```
I'll show examples of [TASK], then a new input. Match the style and format. Example 1: [IN→OUT]. Example 2: [IN→OUT]. Now: [NEW INPUT]
```

### Structured Output
```
[YOUR PROMPT]. Format response as JSON with this schema: [SCHEMA]. Do not include text outside the formatted output.
```

### Self-Critique
```
[YOUR PROMPT]. After your response, add a "Self-Critique" section: 1 potential weakness, 1 missing angle, how to improve.
```

### Reverse Prompting
```
I want to achieve [GOAL]. Ask clarifying questions one at a time until you have enough context, then provide the solution.
```


## Prompt Engineering Cheat Sheet

### The 6-Element Formula
1. **Role** — "You are a [expert role]"
2. **Context** — "I am [situation/background]"
3. **Task** — "Your task is to [specific action]"
4. **Format** — "Output as [format specification]"
5. **Constraints** — "Do not [limitations]"
6. **Examples** — "Here's an example: [input → output]"

### Technique Selection Guide
| Technique | Best For |
|-----------|----------|
| Zero-shot | Simple, well-defined tasks |
| Few-shot | Consistent formatting, style matching |
| Chain-of-thought | Complex reasoning, math, logic |
| Role-playing | Domain expertise, perspective-taking |
| Self-critique | Quality improvement, spotting blind spots |
| Multi-step | Long workflows, collaborative tasks |
| Reverse prompting | Ambiguous problems, exploration |

### Common Mistakes
- Too vague → Be specific about format and constraints
- One giant prompt → Break into steps
- No examples → Show what "good" looks like
- Ignoring context → Explain who you are and what you need
- Accepting first output → Iterate: "improve this by..."
